# 说明
个人画册制作工具，用于简单制作个人画册

# 界面概览
- 需要新建画册，在画册中导入画册的素材，素材就在左边，可以双击预览图片，可以为素材分组。
- 中间位置是画布，也就是画册的页面
- 右边位置是画布中的对象，可以右击裁剪图片等
- 文字分为竖版和横版
- 提供了导出为PDF功能，用来把画册导出为PDF，这样可以去淘宝发给商家打印成画册
