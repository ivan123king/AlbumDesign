# 实现计划

按顺序推进，每阶段通过验收后再进入下一阶段。阶段 0、阶段 1 已完成本机验证；阶段 2 尚未开始。实际进展与验证结果见 [构建与运行](构建与运行.md)。

## 阶段 0：确认文档

- 完成业务规划、技术选型、实现计划和 AI 开发约定。
- 后续需求变化同步维护对应文档及索引。
- 验收：工程结构、删除规则、图片与文字交互、第一版范围一致。

## 阶段 1：搭建可运行框架

- 检查已有 Node.js/npm，配置 Electron、React、TypeScript 和 Vite；固定依赖版本与锁文件，记录运行和打包步骤。
- 建立主进程、preload、React 渲染进程及共享类型的最小结构，启用类型检查与进程隔离。
- 建立主窗口：左侧素材树、中间画布、右侧页面及对象树。
- 中间使用 HTML/CSS 页面容器与绝对定位对象，先验证 A4 尺寸、视图缩放及简单双页 PDF 的尺寸和分页。
- 加入新建工程、打开工程、保存等菜单入口，未实现操作明确禁用。
- 验收：Windows 11 上能够构建启动，窗口缩放正常，三栏可以调整宽度。

## 阶段 2：工程与页面存储

- 定义带格式版本的工程、页面及对象数据模型。
- 使用竖向 A4 基础坐标保存对象，编辑方向与对象自身旋转角度独立保存；顶部方向按钮切换整页视角。
- 新建工程时校验空目录，创建运行所需目录和 `project.json`。
- 实现 A4 横竖页面的新建、命名、切换、排序、保存和重开。
- 实现固定页面编号、递增计数、页面删除及页码自动更新。
- 文件操作通过 preload 的业务接口交给主进程，校验数据与工程内路径，使用异步读写和临时文件替换。
- 处理无权限、JSON 错误和文件缺失，避免覆盖有效数据。
- 验收：排序后目录编号不变；删除后新建不复用编号；重开保持名称、页序和尺寸。删除测试只用临时工程。

## 阶段 3：素材管理与图片排版闭环

- 左侧显示 `assets`，支持新建分组目录、导入图片和同名冲突处理。
- 拖入画布时复制到页面目录，分配图片编号，等比例适应画布并居中。
- 实现选择、拖动、控制点等比例缩放、右键尺寸编辑、删除和方向键微调。
- 实现图片围绕中心顺时针、逆时针旋转 90°，保存自身角度；正确处理整页旋转视图中的选择、拖动和缩放。
- 实现视图缩放与页面物理尺寸分离，显示页面边界。
- 使用 HTML 图片元素与 CSS 变换，明确查看缩放和对象缩放的坐标换算。
- 右侧展开图片对象，支持底层对象选择和叠层调整。
- 加入当前页按需加载、预览图和切页资源释放；拖动仅更新当前对象，避免全界面重复渲染。
- 验收：原图删除或素材移动后页面仍正常；保存重开位置、尺寸、对象角度和叠层一致；整页视角反复切换不累计改变对象数据；删除对象同步删除页面图片，编号继续递增。
- 提前用 300 页图片工程连续切页和拖动，检查是否同时加载无关原图、内存是否持续增长，记录待优化项。

## 阶段 4：横排与竖排文字

- 提供两种可拖入画布的文字框，支持中文输入和再次编辑。
- 两种文字框均支持多行、多列，支持手动回车和按区域自动换行或换列。
- 支持字体、字号、颜色及基本间距设置。
- 使用 HTML/CSS 与 `writing-mode` 排版，文字输入弹窗负责内容编辑；图片与文字共用定位和叠层规则。
- 实现文字框移动、等比例缩放、删除和叠层调整，接入右侧对象树。
- 接入文字框围绕中心正反向 90°旋转；与横排、竖排的书写顺序分别处理。
- 验收：中文、标点、英文数字和换行内容可保存重开；缩放同步改变字体及间距；图片与文字可以交错叠放。
- 同步导出少量文字样例，提前检查竖排、字体和缩放后的行列排布，避免到最后才发现打印差异。

## 阶段 5：保存可靠性与基础易用性

- 实现修改状态提示、自动保存和恢复备份，协调工程文件与页面文件的写入顺序。
- 实现页面复制、图片与文字对象复制粘贴；复制图片分配新文件。
- 处理删除、复制或保存中途失败；删除仍按业务规则移除真实文件。
- 第一版不实现完整撤销系统，尤其不承诺恢复已经删除的页面和图片；后续增加时必须先设计恢复数据。
- 验收：取消未保存关闭操作能继续编辑；正常退出重开不丢数据；模拟保存失败不会静默破坏原有可用数据。

## 阶段 6：PDF 导出与试印闭环

- 使用独立导出窗口，共用页面 HTML/CSS 组件，以 `printToPDF` 按工程页序输出，统一采用竖向 A4 纸张与原图。
- 横版编辑画布整体顺时针旋转 90°放入竖向纸张，保留对象实际大小与相对位置。
- 设置打印分页、背景、零默认页边距和页面边界裁切，移除编辑控制点。
- 等待字体及图片就绪，验证单页、小批量和混合横竖页面；数百页采用受控批次，确有需要再引入 PDF 合并库。
- 检查中文字体、竖排文字、字体嵌入与屏幕排版一致性。
- 验证仅切换编辑视角前后 PDF 布局一致；独立旋转图片或文字框后，PDF 正确保留对象角度。
- 提供导出进度、取消和失败处理，避免失败产物被当作完整 PDF。
- 验收：制作至少 10 页样例，包含横竖版、多图、文字、遮挡和越界对象；检查所有 PDF 页均为竖向 A4、横版内容整体旋转、页序及裁切，并完成小批量试印。

## 阶段 7：数百页优化与交付

- 使用 300～500 页真实图片测试工程评估打开、切页、素材浏览、保存和导出，记录测试机器、耗时与峰值内存。
- 按实测问题调整图片缓存、后台处理、资源释放和导出批次；确有必要时为长列表加入虚拟滚动。
- 缩略图为可选项：仅生成变化页面的缩略图；缺失或关闭时仍显示页码与名称列表。
- 打包 Electron 运行环境与前端资源，记录安装运行方式、已知限制和实际验证环境；成品不要求用户安装 Node.js。
- 验收：目标机器上数百页工程可以完成编辑、保存重开和 PDF 导出；不存在持续累积的大图内存占用；无开发环境的 Windows 11 机器可启动。

## 每阶段完成要求

- 代码有文件注释、功能注释；不引入当前阶段用不到的设计。
- 先验证当前改动涉及的实际风险，避免重复执行无关检查。
- 更新实际涉及的文档；目录或文档文件变化同步更新 `docs/index.md`。
- 记录完成内容、验证结果和剩余事项，不把计划内容写成已完成功能。
