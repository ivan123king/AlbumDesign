# 构建与运行

## 环境与依赖

- 目标：Windows 11 x64；开发环境：Node.js 24、npm。
- 版本固定在 `package.json`，依赖树通过 `package-lock.json` 锁定，不使用全局安装的构建工具。
- `.npmrc` 使用 npm 官方仓库，npm 下载缓存放在 `.cache/npm`。Electron 下载缓存可通过下方进程环境变量放在工程内。
- 初次安装会下载 Electron、React 和构建依赖，不需要安装 C++ 编译器，不修改系统 PATH。

在项目根目录的 PowerShell 中执行：

```powershell
$env:electron_config_cache = Join-Path $PWD '.cache/electron'
npm ci
node node_modules/electron/install.js --no
npm run dev
```

如 GitHub 下载连接失败，可在同一 PowerShell 中临时设置 `$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'` 后重试运行环境安装。保留官方包内置校验，不关闭校验；该设置只影响当前进程环境。打包优先复用工程缓存中的运行环境压缩包。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动桌面开发窗口，前端支持热更新；使用本机 5173 端口 |
| `npm run typecheck` | TypeScript 严格类型检查 |
| `npm run smoke:layers` | 构建并在临时画册验收对象命名、混合对象叠层、列表拖放、菜单和保存恢复 |

| `npm run smoke:recent` | 构建后以四次独立 Electron 启动验收最近画册、设置持久化、路径失效重试及配置异常 |
| `npm run smoke:asset-delete` | 在临时画册中验收两种视图右键删除、分组确认、回收站失败与画布副本/草稿保留 |
| `npm run build` | 类型检查并构建到 `out` |
| `npm start` | 运行最近一次构建，首次使用先执行 build |
| `npm run smoke` | 构建后隐藏运行真实 Electron 检查，输出到 `.cache/verification` |
| `npm run smoke:crop:dev` | 独立随机端口启动真实开发版 React，回归 StrictMode 下裁剪原图显示、关闭重开及完整裁剪流程 |
| `npm run smoke:crop` | 在临时画册验收形状/反向裁剪、连续裁剪、保存放弃、素材替换、真实鼠标及 PDF 透明蒙版 |
| `npm run smoke:text` | 构建后独立验证文字、自由旋转和单页文字打印样例，同样只使用临时画册 |
| `npm run smoke:pdf` | 构建后验收真实十页画册导出、命名、保存、覆盖、打印/合并取消及异常文件保护 |

| `npm run package` | 构建并打包 Windows x64 程序目录到 `release` |

打包后运行 `release/AlbumDesign-win32-x64/AlbumDesign.exe`。目录中的依赖文件需保留，不能只复制 exe。当前不制作安装器、自动更新或代码签名。

## 素材导入操作

左侧“目录 / 预览”切换目录树与缩略图网格，默认显示目录。预览模式的分组下拉框包含子分组；选择同时作为导入位置。双击两种视图中的图片打开原图弹框，Esc 或关闭按钮退出；键盘聚焦图片后按 Enter/空格也可打开。两种视图均支持拖入画布。外部修改素材后点击刷新；失败卡片可单独重试。

1. 点击“新建画册”选择空目录，或点击“打开画册”选择已有画册目录。
2. 左侧点击“素材库”或某个分组名称选择导入位置；三角按钮只控制展开与折叠。
3. 点击“新建分组”输入名称，支持在分组内继续创建子分组。目录名称遵循 Windows 文件名规则，重名不合并。
4. 点击“导入图片”多选 JPEG/PNG。原图复制到选中分组，同名自动改名，原始文件不变；损坏或不支持的文件逐项显示原因，其余成功项保留。
5. 素材及分组直接写入磁盘，关闭后通过“打开画册”恢复；外部修改素材目录后可点击“刷新”。缺失或无效画册会报错，打开失败保持原画册会话。

素材树显示目录和文件名；PDF 导出使用各画布内已复制的原图，不依赖素材库中的原文件。

## 画布与图片操作

1. 打开画册后，点击右侧“新建画布”，输入名称并选择 A4 横竖编辑方向。新画册不自动创建页面。
2. 将左侧一个图片文件拖入白色画布，软件在该页创建独立副本，按比例完整适应画布并居中、置于最上层；重复拖入生成独立对象。
3. 点击图片后拖动调整位置。右侧对象列表按叠层从高到低显示，可选择被遮盖的图片。滚轮只改变查看比例，图片可移出纸张边界。
4. 选中图片后拖四角圆点等比例缩放，拖四边中点沿对象自身方向拉伸，无需按 Ctrl。Esc 取消当前缩放。右击名称调整大小，默认等比；图片可取消勾选后分别输入。尺寸按对象自身长宽显示，不随旋转角度改变。
5. 修改位置、尺寸或顶部横竖视角后，右侧画布名称后显示 `*`，提示尚未保存；点击“保存”或按 Ctrl+S 成功后自动清除。切换视角是整页旋转，原图片方向随整页一起改变；再次拖入的新图片按当时视角摆正。
6. 右侧点击页面切换；右击对应画布名称，可改名、画布上移、画布下移或删除画布。页码按数组顺序重新显示，页面目录编号不变。
7. 图片选中并聚焦画布或对象树后按 Delete，或选中页面后按 Delete/点击“删除画布”；确认后删除真实页面文件。输入框和素材区域的 Delete 不触发页面删除。

页面创建、页面改名、排序、图片加入及对象删除即时提交；对象名称、文字创建/编辑、位置、尺寸、角度、叠层与方向修改需手动保存。有未保存修改时，切页、切换画册、关闭及结构操作先询问“保存 / 放弃修改 / 取消”。保存失败保留未保存状态。定时自动保存、恢复备份和完整撤销尚未实现。

## 对象命名操作

1. 右击当前画布下的图片或文字，选择“改名”，输入名称并确定；Enter 确认，Esc 或取消关闭。
2. 需要恢复来源文件名或文字摘要时，在同一弹窗点击“恢复默认名称”。修改后使用保存或 Ctrl+S 提交。
3. 悬停对象行查看完整名称，图片同时提示来源文件名；尺寸弹窗同步显示自定义名称。具体命名与保存规则见 [业务规划](../业务/业务规划.md#对象名称)。

对象命名验收并入 `smoke:layers`，截图为 `object-name-dialog.png` 与 `object-names-list.png`，结果记录在 `layers-report.json`。仅使用图层专项的临时画册。

## 图层操作

1. 当前画布下对象列表的上方就是画面顶层，图片与横竖文字混排；新增对象默认置顶。
2. 拖动对象名称，根据插入线上下放置；右击名称也可选择“上移一层”“下移一层”“置顶”“置底”，边界操作禁用。
3. 松手立即查看叠放效果，Esc 或拖出有效区域取消；只支持当前页内排序。选中底层对象不会自动置顶。
4. 图层调整后通过保存或 Ctrl+S 提交。画布名称右键菜单中的“画布上移/画布下移”调整的是页序。

图层专项输出 `layers-report.json`、文字/图片置顶对照截图、菜单、插入线及小窗口截图，测试工程位于 `.cache/verification/图层验收-*`。拖放通过 DOM 的 DragEvent/DataTransfer 及真实 preload/IPC 执行，右键使用 Chromium 鼠标输入；不等于原生鼠标手工验收。

## 文字与自由旋转操作

1. 在已有画布中点击顶部“横排文字”或“竖排文字”，也可把按钮拖入画布指定落点；填写内容、字体及样式后确认创建，取消不产生对象。
2. 双击文字框或右击右侧文字名称选择“编辑文字”，可再次编辑。横排支持分栏，竖排自动由右向左换列；编辑排版区长宽会重新换行，超出区域会提示。确认后画布选框紧包裹实际文字，仅留半毫米边距；旧文字再次编辑确认后收紧。
3. 文字只有四角缩放点，始终等比放大文字、字间距和行列间距，缩放本身保留原换行；没有四边中点。文字的右键尺寸也只能等比修改。
4. 图片与文字选框上方都有旋转图标，按住拖动鼠标绕对象中心实时旋转；松手确认，Esc 或失焦取消。角度与整页方向独立，旋转后仍可继续移动或缩放。
5. 右侧名称与画布选择同步，可选择被遮盖对象；右键提供尺寸、文字编辑及正反向 90°旋转。文字不产生图片文件，也不消耗图片编号。
6. 修改后右侧画布名出现 `*`，点击保存或按 Ctrl+S。旧版纯图片页面可打开，增加文字或自由角度后保存为新版页面格式；旧程序无法读取新版页面。
