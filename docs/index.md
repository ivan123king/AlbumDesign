# 文档索引

本项目用于在 Windows 11 上手工制作多页画册，并导出 PDF。

技术方案：Electron + React + TypeScript，使用 HTML/CSS 实现画布与文字排版，Vite 构建前端。

PDF 规则：所有页面统一竖向 A4；软件横版内容导出时整体顺时针旋转 90°。

## 阅读方式

- 先查看索引，再按任务读取所需文档，不一次性读取或递归列举整个 `docs`。
- 确认功能看业务规划；确定技术方案和开发顺序看开发文档。
- 画册、页面、素材原图/缩略图预览、图片基础编辑、横竖文字、文字四角等比、自由旋转、图层调整及对象名称已通过本机自动验收。素材预览已测 500 张合成图；真实照片集、人工验收与真实大工程/PDF 性能尚未完成。

## 维护规则

- 所有仓库维护目录新增、删除、移动或重命名，都必须同步更新本索引的目录清单及相关链接。
- 文档文件新增、删除、移动或重命名，也必须更新本索引。
- 后续新增源码、资源、测试等维护目录时，同样登记在目录清单中。
- 画册运行数据、构建产物和临时缓存不逐项登记。
- 业务变更更新业务文档；技术及实施变更更新开发文档。
