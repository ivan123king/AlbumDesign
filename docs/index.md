# 文档索引

本项目用于在 Windows 11 上手工制作多页画册，并导出 PDF。

技术方案：Electron + React + TypeScript，使用 HTML/CSS 实现画布与文字排版，Vite 构建前端。

PDF 规则：所有页面统一竖向 A4；软件横版内容导出时整体顺时针旋转 90°。

## 阅读方式

- 先查看索引，再按任务读取所需文档，不一次性读取或递归列举整个 `docs`。
- 确认功能看业务规划；确定技术方案和开发顺序看开发文档。
- 画册、页面、素材原图/缩略图预览、图片基础编辑、横竖文字、文字四角等比、自由旋转、图层调整及对象名称已通过本机自动验收。素材预览已测 500 张合成图；真实照片集、人工验收与真实大工程/PDF 性能尚未完成。
- 软件设置及最近画册启动恢复已通过独立临时配置的四次进程启动和异常验收；原生菜单、单实例激活与跨机器分发仍待人工确认，详见构建与运行。
- 左侧分组/素材右键删除已通过临时画册专项与素材预览界面回归，包含取消、回收站失败及画布副本/未保存草稿保留；自定义告警与关于弹窗已通过真实 DOM、Esc、重载取消及最小窗口验收，原生鼠标和回收站恢复仍待人工验收。
- 真实画册 PDF 已接入名称日期命名、保存确认、逐页打印、后台合并、进度取消及旧文件保护。十页临时画册、独立 PDF 解析/渲染和文字回归已通过；实体试印与真实 300～500 页性能待验收，详见构建与运行。
- 左右图片形状裁剪已接入：统一八点/旋转、反向裁剪、按钮预览、素材替换与页面草稿；允许控制框越界、旋转保持尺寸；开发模式图片加载、工具栏对齐与自定义未保存提示的验收及性能边界见构建与运行。
