# 业务规划

## 第一版目标与范围

用户在 Windows 11 上建立独立画册工程，管理图片素材，手工排版多页 A4 图片与中文文字，按页序导出 PDF。

第一版包含图片移动、等比例缩放与单方向拉伸、图片与文字框独立旋转、两种文字框、对象叠层、页面管理和工程保存。不包含图片内部裁剪、自动对齐、自动排版、复杂富文本及专业出版功能。右侧缩略图可后续增加。

## 主界面

界面统一称为“画册”，文件菜单与工具栏使用“新建画册”“打开画册”，提示文字采用相同称呼。

| 区域 | 行为 |
| --- | --- |
| 左侧素材树 | 显示 `assets` 下的目录与图片，导入外部图片，新建目录进行分组 |
| 中间画布 | 显示当前页，接收图片与文字框，支持选择、移动和缩放 |
| 右侧页面对象树 | 显示页码与画布名；展开页面显示对象，按从顶层到底层排列 |

点击页面切换画布，点击对象选中对应对象，包括被遮盖的底层对象。对象右键菜单提供尺寸修改、顺时针或逆时针旋转 90°、上移一层、下移一层、置顶、置底和删除。图片与文字共用叠层规则。

## 工程目录

新建工程选择一个空目录；打开工程选择已有工程目录。

```text
画册目录/
├─ project.json
├─ assets/
│  └─ 用户分组目录与素材图片
├─ pages/
│  ├─ 001/
│  │  ├─ canvas.json
│  │  ├─ 001.jpg
│  │  └─ 002.png
│  └─ 002/
│     └─ canvas.json
└─ cache/
   └─ thumbnails/
      ├─ 001/
      └─ 002/
```

- `project.json` 记录工程信息、默认页面方向、页面名称、页面排列顺序与固定目录编号，以及下一个页面编号。
- `canvas.json` 记录本页纸张尺寸、编辑方向、下一个图片编号，以及图片和文字对象的位置、尺寸、自身旋转角度和叠层等排版数据。
- 页面图片引用本页目录中的文件名，不引用外部绝对路径或依赖素材库位置。
- `cache` 内容可以删除并重新生成，不保存不可恢复的原始内容。

## 编号与页码

- 页面目录编号固定，至少三位，如 `001`、`002`；超过三位自然递增。
- 页码从 1 开始，由 `project.json` 中页面排列顺序决定。改变页序不改变目录编号。
- 页面删除后编号不复用；计数不能只按现存目录最大值重算。
- 图片在各自页面内从 `001` 递增，保留原图片后缀；删除后继续使用新编号。
- 一个图片对象对应一个独立页面图片文件。重复拖入、复制粘贴或复制页面时保持该约定。
- 对象有稳定 ID；图片文件编号、对象 ID 与叠层顺序分别管理。

## 页面

- 软件默认 A4 竖版，宽 210 mm、高 297 mm；横版编辑视图宽 297 mm、高 210 mm，便于横向阅读与排版。
- 每个画布目录保存一页，记录竖向 A4 纸张尺寸与编辑方向；PDF 输出纸张统一为竖向 A4。
- 顶部方向按钮改变当前画布的编辑视角：横版切竖版，整页连同内容顺时针旋转 90°；竖版切横版则逆时针旋转 90°。
- 切换视角保留图片和文字的实际尺寸、相对位置及自身旋转设置；不重新排版。仅切换视角不会改变最终 PDF 的内容布局。
- 支持新建、命名、切换、复制、排序与删除。
- 页码自动分配，显示名称可修改；目录编号不随名称改变。
- 右侧画布名称后用 `*` 标记未保存修改，悬停提示“未保存修改”；长名称省略时仍保留标记。保存成功或放弃修改后标记消失，保存失败时保留；星号仅用于界面提示，不写入画布名称。

## 素材与图片

1. 外部图片导入素材库时复制到 `assets`，同名冲突生成新名称，不覆盖已有素材。
2. 素材拖入画布时，再复制到当前页目录，并分配新的图片编号。
3. 新图片保持长宽比，完整适应画布并居中，默认放到最上层。
4. 点击图片内部选择并拖动改变位置；选中后显示八个圆形控制点：四角始终等比例缩放，对角固定；四边中点只改变对应方向尺寸，对侧边固定。无需按 Ctrl，最小长宽为 1 mm；Esc 取消本次缩放。
5. 不提供图片内部裁剪。图片可以超出画布，PDF 导出时按页面边界裁切。
6. 滚轮仅缩放画布查看比例，不改变页面尺寸、对象尺寸或打印尺寸。
7. 素材库的改名、移动或删除不影响已经放入页面的图片。

首批支持 JPEG、PNG；不支持的格式明确提示。图片原文件不做覆盖式修改。

- 右侧点击画布名称显示该页图片，点击图片名称与画布选中状态同步。被遮盖图片的选框及控制点显示在编辑层上，不改变图片叠层；控制点位于纸张边缘时仍可点击。
- 右击右侧对象名称，先选中对象，再通过调整大小打开尺寸对话框。长度与宽度指对象自身未旋转的长宽，单位为 mm；自由旋转不改变尺寸读数，修改尺寸后中心固定。
- 尺寸对话框的“等比例缩放”默认勾选，仅长度可输入，宽度按打开对话框时的当前图片比例自动计算并只读；取消勾选后长度与宽度可分别输入。确认应用，取消不修改。
- 单击或通过右侧名称选中图片只改变选择状态，即使图片越出纸张边界，也不得改变其在纸张内的显示位置、保存坐标或尺寸；选框始终与图片边界重合。
- 边中点或尺寸表单中的非等比例调整会拉伸图片内容，保持原图文件完整。缩放松手或表单确认后进入未保存状态，沿用手动保存及离页确认流程。

## 文字

- 提供横排、竖排两种可拖入画布的文本框。
- 顶部按钮可点击创建，也可拖到画布落点创建。弹窗确认后生成真实文字对象，取消不创建；双击文字或右侧右键“编辑文字…”再次编辑。
- 横排：字从左到右，写满后向下换行；需要分列时，列从左到右排列。
- 竖排：字从上到下，写满后向左换列。
- 两种类型均支持多行、多列和手动回车，相关排布参数随文字对象保存。
- 支持中文内容、字体、字号、颜色与基本字间距和行列间距。首批字体为检测到已安装的微软雅黑、宋体、黑体、楷体、仿宋；缺失字体明确提示，不静默替换保存的字体。
- 文字框只显示四个角点，始终等比例缩放，不提供四边中点；文字、字间距和行列间距一起变化，保留原有排布比例。右键尺寸同样只能等比例调整。
- 内容编辑时按当前区域排版；缩放操作本身不通过重新换行改变原有排布。
- 横排支持 1～8 栏，竖排在区域内自动由右向左换列；编辑弹窗可调整排版区域重新换行，溢出时提示。文字、字体和排版参数保存在页面 JSON 中，不生成图片副本，不消耗图片文件编号。
- 创建、编辑、移动、缩放和旋转文字进入未保存状态，沿用手动保存和右侧 `*` 标记；删除文字只移除对象记录。
- 支持文字框移动、再次编辑、叠层调整和删除。第一版不要求在画布内直接显示编辑光标。

## 对象独立旋转

- 图片和文字选框的顶边中点外侧有旋转图标，以短连线连接。按住拖动鼠标时围绕对象中心实时自由旋转，允许跨过 0° 连续转动；松手确认，Esc 或失焦取消本次旋转。
- 选框及缩放控制点跟随对象自身角度，旋转后仍沿自身边缘缩放。图标与控制点保持易于点击的固定屏幕大小；文字只有四角缩放点。
- 右键保留顺时针或逆时针旋转 90°的便捷操作；角度独立保存为任意有限角度。
- 以对象中心旋转，中心位置、实际宽高和叠层保持；旋转角度独立保存，重新打开与 PDF 导出保持一致。
- 图片旋转只改变页面中的摆放方式，不修改原始图片文件。
- 文字框旋转会带着所有文字一起转；横排、竖排仍由文字框类型决定，旋转不改变字的书写顺序。
- 整页方向切换与对象独立旋转分开处理。例如整页转回竖版后，可以单独把某张照片或文字框转正。

## 删除

- 选中页面按 Delete：删除对应 `pages/编号` 目录，更新工程页面列表，后续页码自动调整，并清理该页缓存。
- 选中图片对象按 Delete：删除对应页面图片文件及 `canvas.json` 中的对象记录，不删除 `assets` 原素材。
- 选中文字框按 Delete：删除该文字对象记录。
- 正在输入文字时，Delete 由文字编辑器处理，不触发页面或对象删除。
- 删除属于真实文件删除；完整撤销恢复暂不纳入第一版。

## 保存与 PDF

- 支持手动保存、自动保存与恢复备份；重新打开工程恢复页面顺序、对象位置、尺寸、内容和叠层。
- 整个工程目录复制或移动后仍可打开。编辑所需字体缺失时应提示，不能静默改变排版。
- PDF 按工程页序输出，一个画布对应一页，所有 PDF 页面统一为竖向 A4（宽 210 mm、高 297 mm）。
- 竖版内容直接输出；横版画布的图片、文字等整体顺时针旋转 90°后输出，保留排版比例与实际尺寸。横竖版的区别体现在内容朝向，不改变 PDF 纸张方向。
- 导出使用页面原图，保持图片与文字叠层；所有越界内容按页面边界裁切。
- 第一版采用页面对象树列表即可完成全部操作，缩略图缺失不影响使用。
- 正式制作前确认商家的成品尺寸、留白和交稿要求。第一版以 A4 页面边界导出，不自动增加出血或拼版。
